# 💖 Happy Birthday, Annanya | A Cinematic Animated Love Story

> **A luxury, animated single-page love story website created with eternal devotion for Annanya by Krishna.**

---

## 🌟 Key Features & Highlights

- **🎭 Theater Velvet Curtains & Flying Kiss Gate**:
  - High-end romantic entrance featuring an animated heartbeat counter (`0%` ➔ `100%`), glowing 3D heart-flame hybrid motif, and interactive **`💋 SEND A FLYING KISS TO OPEN`** button.
  - Clicking the kiss button triggers an **explosive 360° flying kiss burst** (`💋`, `😘`, `💖`, `✨`, `🌹`) accompanied by velvet theater curtains parting to reveal the website!

- **💌 Folded Parchment Love Letter**:
  - Embedded folded vintage letter card with wax stamp `💌`, exact Hindustani romantic letter written for **Annanya** on **Mahashivratri (15 February)**, detailing bike rides, warm hugs, playful tantrums, and signed by **Krishna**.
  - Includes signature **Moon & Flickering Diya Motif** (*"ek diya jo us raat se aaj tak jalta hi raha hai"*).

- **📸 101 Photo Memory Vault Integration**:
  - Includes all 101 local romantic photos from the `Cluster 2` collection.
  - Interactive **Memory Vault Modal** showing all 101 photos in an animated grid.
  - **`🔀 Shuffle Memories`** button to dynamically swap photos across website slots.
  - Drag-and-Drop photo upload modal with `localStorage` persistence.

- **✨ 7 Interactive & Animated Sections**:
  1. **Hero Section**: Letter-by-letter springy bounce Overshoot title (*"Happy Birthday, Annanya"*), word-by-word fade subtitle (*"ek diya jo us raat se aaj tak jalta hi raha hai"*), and gold self-drawing line sweep.
  2. **Love Letter Section**: Folded vintage parchment paper letter card with wax seal.
  3. **Asymmetric Photo Gallery**: 5-card magazine grid with staggered entrance, zoom images, and hover overlay captions.
  4. **Reasons I Love You**: Typewriter heading reveal and 6 list rows with rose-glowing numbers (01–06) sliding in on scroll.
  5. **Poem & Our Journey**: Staggered poem line fade-ups and 5-milestone interactive vertical timeline.
  6. **Sacred Vows**: 6 promise cards with 3D perspective tilt (`rotateX(15deg)`) and cursor-tracking radial gradient glow sweeps.
  7. **Finale Celebration**: Rotated Polaroid frames, springing *"I Love You"* title, editable name (`Annanya ❤️`), gold underline sweep, and 5-epicenter **Fireworks Celebration Engine** (`canvas-confetti` + 30 flying emoji bursts + rising hearts + white screen flash).

- **🎨 Romantic Aesthetic**:
  - Palette: Deep Midnight Plum (`#2a0f2e`), Deep Violet (`#1c0a1e`), Raspberry Magenta (`#7a2452`), Rose Blush (`#c9536f`), Glowing Diya Gold (`#f0a63c`), Soft Gold (`#ffd9a0`), and Parchment (`#faf1e2`).
  - Typography: **Yatra One**, **Mukta**, **Caveat**, **Cormorant Garamond**, and **Great Vibes**.
  - Custom heart-shaped cursor tracking mouse with trailing gold ring & rose petal sparkles.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/) + React 19
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Google Fonts (`Yatra One`, `Mukta`, `Caveat`, `Cormorant Garamond`, `Great Vibes`)

## 🚀 How to Run Locally

### 1. Next.js Version (Recommended)

```bash
# Navigate to love-app
cd love-app

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Standalone Single HTML Version

Run a local HTTP server from the root directory:

```bash
python -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

## 🌐 Deploy to Netlify

### Option 1: Netlify Drag & Drop (Fastest — 10 Seconds)
1. Go to **[app.netlify.com/drop](https://app.netlify.com/drop)**.
2. Drag and drop the `Cluster 2` project folder.
3. Your site will instantly go live with a free `.netlify.app` URL!

### Option 2: Deploy via GitHub / Git
1. Push this repository to **GitHub**.
2. Connect your repository on **[app.netlify.com](https://app.netlify.com)**.
3. Set build settings:
   - **Base directory**: `love-app`
   - **Build command**: `npm run build`
   - **Publish directory**: `.next`
4. Click **Deploy Site**!
